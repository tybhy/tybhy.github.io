帮助文档

快速上手5 步搭建第一个智能体→
操作步骤
  1. 登录平台后，点击左侧导航「智能体开发与管理」进入智能体列表页。
  2. 点击「新建 Agent」，输入名称：选择「空白创建」从头搭建，或「从模板创建」从模板库选择一个模板快速起步（智能客服增强版 / 数据分析助手 / 多工具编排，点击「克隆到画布」即可加载）。
  3. 在画布中从左侧节点库拖入节点（大模型、知识库检索、条件选择等），从节点右侧圆点拖出连线，接到下一节点左侧圆点，形成流程。
  4. 单击「大模型」节点，在右侧配置面板选择模型并填写提示词；模型需先在「模型配置」页添加并启用。
  5. 点击「保存」，再点击「运行」测试（运行面板可输入 JSON 参数，留空使用默认值），通过后点击「发布」，到资产中心「智能体应用」tab 即可使用。
常见问题
Q：新建 Agent 后在哪里配置模型？
A：在画布中选中「大模型」节点，在右侧配置面板选择模型并填写提示词；模型需先在「模型配置」页添加并启用。
Q：可以不选模板直接空白创建吗？
A：可以。空白画布从「开始」节点拖起，按需添加节点并连接即可，结构与模板创建完全一致。
画布视图节点编排、连线、运行与配置详解→
操作步骤
  1. 进入智能体后自动打开画布视图：左侧节点库按 8 组分类列出节点（触发/入口、AI 能力、集成/工具、代码类、逻辑控制、结构复用、人机协同、出口），拖拽到画布即完成添加。
  2. 连线：从节点右侧圆点拖出连线，松开到目标节点左侧圆点；连线方向即数据流向。「条件选择」节点可配置多条分支实现多分支/并行，多条连线汇入同一节点即为汇合。
  3. 配置：单击节点，在右侧配置面板设置参数（模型、提示词、条件分支、HTTP 地址等），修改后点击「保存」生效。
  4. 运行：点击顶部「运行」按钮，在运行面板输入参数（JSON），点击「运行」查看各节点执行结果；输入可留空使用默认值。右键节点可运行单个节点、设置断点或禁用。
  5. 编辑辅助：顶部「撤销 / 重做」按钮（快捷键 Ctrl+Z / Ctrl+Y）回退或重做画布操作；滚动滚轮缩放画布，画布右上角显示当前缩放比例。
  6. 模板：画布顶部「模板」tab 提供 3 个网状模板（含并行分支与汇合结构），点击「克隆到画布」后在此基础上修改。
常见问题
Q：节点之间如何连线？
A：从节点右侧圆点拖出连线，松开到目标节点左侧圆点即可；连线顺序即数据流向，删除连线可选中后按 Delete 键。
Q：怎么运行并查看结果？
A：点击「运行」打开运行面板，可输入 JSON 入参（留空用默认值），运行后逐节点展示结果；右键节点可单独调试该节点。
代码节点 & DevToolsPython 入口规范、AI 代码助手→
操作步骤
  1. 在画布节点库「代码类」中拖入「代码」节点，点击节点进入「代码视图」编辑对应代码。
  2. 代码入口固定为 async def main(input) -> dict：通过 input.params 读取上游传入的参数（如 input.params.get("query")），处理完成后返回 dict 作为节点输出。
  3. 编辑区内置代码模板与工具函数库：可从模板快速插入常用代码（如 HTTP 请求模板，使用引擎白名单模块 requests_async），也可在「工具函数库」中新建可复用函数（tools/ 目录）并插入到当前代码。
  4. AI 代码助手：选中代码段后，在 AI 助手输入框中提问、要求改写、添加注释或代码审查，生成结果可一键替换选中内容。
  5. 保存后点击「运行」验证执行结果（运行面板可填输入参数），通过后再发布；保存/发布记录可在版本历史中查看。
常见问题
Q：代码节点入口函数格式是什么？
A：必须为 async def main(input) -> dict，参数通过 input.params 读取，返回值必须是 dict。
Q：代码修改后如何确认生效？
A：先「保存」再「运行」，在运行面板结果中核对输出；发布后也可到「智能体管理」点击「对话」验证效果。
工具 & MCP 集成工具 CRUD、HTTP 节点、代码工具函数→
操作步骤
  1. 进入「插件管理」页：点击「+ 新建工具」打开新建弹窗，填写名称、选择类型（mcp：MCP 协议工具 / http：HTTP 接口工具 / builtin：平台内置工具 / other：其他），按需填写描述与 config 配置（JSON 文本，原样存储），保存后工具出现在列表。
  2. 工具列表卡片提供完整管理：点击「编辑」修改名称/config，点击「停用 / 启用」切换状态，点击「删除」移除（删除前需二次确认，删除后不可恢复）。
  3. 画布中使用 HTTP 能力：拖入「HTTP 请求」节点（集成/工具分类），在配置面板填写 URL、请求方法（GET/POST 等）、Headers、Body（支持 EMPTY / JSON / 原始文本）以及超时时间与重试次数，保存后随工作流一起运行。
  4. 代码节点作为工具：在「代码视图」的「工具函数库」中新建函数（tools/ 目录），把通用逻辑（如 HTTP 调用封装）沉淀为可复用函数，任意代码节点均可插入复用。
常见问题
Q：mcp 类型工具是做什么的？
A：用于连接遵循 MCP（模型上下文协议）的外部服务，作为智能体调用外部能力（检索、查询等）的通道。
Q：工具 config 怎么填？
A：config 为 JSON 文本、原样存储，例如 {"url":"http://example.com/api"}；具体字段由工具实现定义。
发布与部署发布流程、可见范围、对话测试→
操作步骤
  1. 在画布或代码视图完成编排并「保存」后，点击「发布」按钮打开发布弹窗；若存在未保存修改，发布会被拦截并提示。
  2. 在弹窗中确认版本号，按需填写版本说明（可选，如本次变更内容）。
  3. 选择可见范围：私用（仅自己）/ 公开（所有人），确认发布；发布后可在智能体管理卡片随时切换。
  4. 发布成功后到「智能体管理」查看已发布智能体，点击卡片上的「对话」按钮进入对话页测试：输入消息与智能体对话，验证流程与回复效果。
常见问题
Q：发布前需要先测试吗？
A：不需要，可直接发布；发布后可到「智能体管理」点击「对话」测试验证流程。
Q：发布后在哪里使用？
A：「智能体管理」页查看已发布智能体，点击卡片上的「对话」按钮进入对话页测试；也可点击「导出」下载 DSL 用于其他环境。
API 参考REST API 接口文档→
常用接口
  1. 登录：POST /api/passport/web/email/login/（邮箱登录，成功后写入会话 Cookie，后续请求自动鉴权）。
  2. 知识库：/api/knowledge/list（列表）、/api/knowledge/create（新建）、/api/knowledge/delete（删除）、/api/knowledge/document/create（上传文档）、/api/knowledge/document/list（文档列表）、/api/knowledge/document/delete（删除文档）。
  3. 工作流：/api/workflow_api/create（新建）、/api/workflow_api/save（保存）、/api/workflow_api/test_run（测试运行）、GET /api/workflow_api/get_process（查询运行进度）、/api/workflow_api/publish（发布）。
  4. 模型调用统计：/api/model/call_stats（调用次数统计）、/api/model/list（模型列表）。
调用约定
  1. 请求默认 POST + JSON body（标注 GET 的接口除外），携带当前登录会话（同源 Cookie）完成鉴权，无需单独申请密钥。
  2. 响应统一结构 {"code":0,"msg":"","data":...}：code=0 表示成功，code≠0 表示失败，msg 为错误说明，业务数据在 data 中。
常见问题
Q：调用 API 需要单独申请密钥吗？
A：不需要，接口走登录会话鉴权，浏览器中登录后同源请求自动携带凭据。
Q：接口返回结构是什么？
A：统一为 {"code":0,"msg":"","data":...}，code 非 0 表示失败，msg 为错误说明；业务数据在 data 中。
